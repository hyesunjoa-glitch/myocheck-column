## ③ 2027 토정비결과 사주 신년운세, 뭐가 달라요? (괴짜Z, tojeongbigyeol-vs-saju-2027)
1. **통과** — 사주는 태어난 시간까지 넣음 / 근거: 네 기둥(연·월·일·시)
2. **통과** — 2027년이 내 기운을 채워 주는지, 넘치는 쪽에 얹히는지 / 근거: 세운과 원국의 오행 균형(부족 오행 보충 vs 과다)
3. **통과** — 같은 해라도 힘이 붙는 해 / 속도 조절할 해 / 근거: 세운이 용신 쪽인지 기신 쪽인지 (칼럼엔 용어 없음)
- 사실 확인: 토정비결 = 음력 생년월일·생시 미사용·144괘·월별 문장 (주간경향 「토정비결의 저자는 토정이 아니다」), 이지함 저작 근거 불확실. 2027 설날 2월 7일(달력닷컴), 입춘 2월 4일(신년② 글과 같음).

## ④ 무료 신년운세랑 사주 신년운세, 뭐가 달라요? (괴짜Z, free-newyear-fortune-vs-saju)
1. **통과** — 태어난 시간이 다르면 기운의 모양이 달라짐 / 근거: 시주
2. **통과** — 2027년이 채워 주는 해 vs 얹히는 해 / 근거: 세운과 원국 오행 균형
3. **통과** — 움직이기 좋은 달 / 근거: 월운 → 결과지 7장
- 주의: 무료 운세를 깎아내리지 않게 「넓게 말하는 것」으로 표현. 특정 서비스 이름 없음.

## ⑤ 사주로 신년운세 보려면 뭐가 필요해요? (괴짜Z, what-you-need-for-saju-newyear-fortune)
1. **통과** — 네 가지 재료 / 근거: 사주팔자 구성
2. **통과** — 시간이 빠지면 같은 날 태어난 사람과 덜 구분 / 근거: 시주 미상
3. **통과** — 재료가 정확할수록 내 얘기 / 결과 약속 없음
- 사람 판단: 상품 입력 화면에서 「시간 모름」 선택이 되는지는 칼럼에 적지 않음(확인 전).

## ⑥ 일주로 보는 2027년 운세, 일주만 보면 될까요? (괴짜Z, ilju-2027-fortune)
1. **통과** — 태어난 날 두 글자 = 나 자신에 가장 가까운 자리 / 근거: 일주(일간 중심)
2. **통과** — 도와주는 칸·막는 칸은 해·달·시간에 달림 / 근거: 원국 내 생극 관계
3. **통과** — 같은 날 태어나도 갈림 / 근거: 연·월·시주 차이
- 본문에 「일주」 용어 사용(검색어라 제목에 필요) — 첫 소제목에서 쉬운 말로 풀이. 「사주로 보면」에는 용어 없음(빌드 경고 0).
