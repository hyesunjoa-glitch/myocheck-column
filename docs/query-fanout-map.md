# 질문 쪼개기 지도 — 상품마다 「AI가 쪼갤 질문」과 칼럼 빈칸 (2026-11-14)

근거: GEO 강의 Part 2 Ch01-01 p.19(쿼리 팬아웃 역설계), Part 1 Ch03-02 p.5③(서브쿼리 역설계).
AI는 「재회 사주 봐줘」 같은 질문 하나를 작은 질문 4~5개로 나눠 각각 찾아본다고 해요 [강사 주장].
그래서 상품마다 「판단 기준 · 원인 · 시기 · 어디서 볼지 · 주의할 점 · 그다음」 칸을 칼럼이 하나씩 덮어야 해요.

- ✅ = 칼럼 있음 / ☐ = 빈칸 / 근거는 실제 검색어·고민 원문(research/, 공개 안 함)
- 빈칸 중 실제 검색어·고민 근거가 있는 것만 12월 계획(docs/december-plan-brief.md)으로 넘겨요.
