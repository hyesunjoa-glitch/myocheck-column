# 칼럼 사주 검수 기준 (v1, 2026-10-05)

묘책 칼럼의 「사주로 보면」과 글 속 사주 문장을 검수하는 기준이에요.

## 누가 검수하나

1. **AI가 먼저 봐요 (1차 검수)**
   - 줄마다 어떤 사주 개념에 기대는지 메모해요.
   - 기준에 어긋난 줄은 고친 문장을 제안해요.
   - 금지어와 용어를 찾아요.
2. **사람이 마지막에 승인해요**
   - AI 제안을 보고 받아들일지 정해요.
   - 글 상태를 「승인」으로 바꾸고, 검수자 칸에 실제 사람 이름을 적어요.
   - AI만 보고 끝난 글에는 "검수"라고 쓰지 않아요.

## 기준 1. 줄 수

- 「사주로 보면」은 3~4줄이에요.
- 4줄이 넘으면 빌드가 발행을 막아요.

## 기준 2. 용어는 쓰지 않아요

칼럼은 처음 온 사람이 읽는 글이에요. 아래 같은 사주 용어 대신 쉬운 말을 써요. 용어는 결과지(유료)에서 풀어줘요.

| 쓰지 않는 말 | 대신 쓰는 말 (예) |
|---|---|
| 비견·겁재 (비겁) | 자기를 지키는 힘, 고집, 경쟁하는 마음 |
| 식신·상관 (식상) | 표현하는 힘, 마음을 밖으로 내는 기운 |
| 편재·정재 (재성) | 다루는 대상·돈의 흐름 / 남자 사주에서 연인을 뜻하는 자리 |
| 편관·정관 (관성) | 책임·규칙·압박 / 여자 사주에서 연인을 뜻하는 자리 |
| 편인·정인 (인성) | 받아들이는 힘, 기대고 싶은 마음 |
| 합 | 두 기운이 묶이는 때 |
| 충 | 두 기운이 정면으로 부딪히는 때 |
| 대운 / 세운 / 월운 | 10년 흐름 / 그해 흐름 / 그달 흐름 |
| 일간·일지·월지 | (자리 이름은 쓰지 않고 뜻만) |
| 용신·신살·격국 | 칼럼에서는 다루지 않음 |

- 용어가 들어가면 빌드할 때 ⚠️ 경고가 떠요(발행은 막지 않아요).

## 기준 3. 세기는 3단계

- 5단계: 결과를 장담하고 겁도 줘요. (예: "상상도 못 한 큰 돈이 들어옵니다")
- **3단계: 방향은 분명하게 말하고, 결과를 약속하거나 겁주지 않아요.** ← 우리 기준
- 1단계: "~하기 쉬워요"만 써요.

| 5 (쓰지 않음) | 3 (이렇게) |
|---|---|
| 당신 인생, 37세부터 완벽히 재설계됩니다 | 37세부터, 인생의 판이 다시 짜여요 |
| 치명적인 변곡점입니다 | 방향이 크게 꺾이는 시점이에요 |
| 10년이 통째로 낭비될 수 있습니다 | 이 10년을 버티기만 하다 보낼 수 있어요 |
| 상상도 못 한 큰 돈이 들어옵니다 | 뜻밖의 기회가 큰돈으로 이어지기 쉬운 해예요 |

**이런 문장은 고쳐요**
- 결과를 약속하는 문장: "연락이 와요" → "연락이 오기 쉬워요"
- 끝을 선고하는 문장: "보기만 하다 끝나요" → "보기만 하다 멀어지기 쉬워요"
- 그 사람 속마음을 단정하는 문장: "흔들리니까 안 보이게 한 거예요" → "흔들리니까 안 보이게 한 경우가 많아요"
- 하루 단위 날짜를 약속하는 문장: "날짜로 잡혀요" → "시기로 잡혀요"

## 기준 4. 쓰지 않는 내용

- 질병·죽음·사고·파산·이혼을 예언하는 말
- "반드시, 무조건, 100%, 확실히, 틀림없이"
- 집착을 부추기는 말: 계속 연락하기, 찾아가기, 몰래 보기, 부계정
- 두 사람 사주를 보지 않고 그 사람 속마음을 확정하는 말
- 개념에 없는 말을 사주인 것처럼 지어내는 말

## 기준 5. 근거 메모

- 줄마다 어떤 사주 개념에 기대는지 검수 기록에 적어요. 화면에는 나오지 않아요.
- 예: "그 사람 사주에서 연인을 뜻하는 자리" → 연인 자리(여자 사주는 관성, 남자 사주는 재성)
- 예: "부딪히는 기운이 풀리는 해" → 충이 풀리는 세운
- 개념을 댈 수 없는 줄은 고치거나 빼요.

## 기준 6. 말투

- 묘화·유리는 존댓말이에요.
- 한 번에 읽히는 문장으로 써요. 두 번 읽어야 하는 문장은 다시 풀어 써요.
- 마지막 줄은 "두 사람 사주를 같이 봐야 보여요"처럼 상품으로 이어 줘요. 이때도 결과는 약속하지 않아요.

## 검수 결과 판정

- **통과**: 그대로 둬요.
- **고침 제안**: AI가 고친 문장을 함께 적어요. 사람이 받아들이면 바꿔요.
- **사람 판단**: 사주 해석 자체가 맞는지 사람이 확인해야 하는 줄이에요.

검수 기록은 `docs/review-log/날짜.md`에 남겨요.
